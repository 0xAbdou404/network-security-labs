# network-security-labs

Hands-on networking and security labs, built and tested in an isolated lab environment.

## About me
Hi, I'm Nemmour Abderrahman, a Master 1 student in Networks and Distributed Systems. I am building these labs to learn how network protocols work
and how they can be attacked and defended. Goal of this labs to build solid foundations 

## Lab environment
- Host: Windows, 16 GB RAM
- VM: Ubuntu Desktop LTS in VMware (NAT for early labs, isolated network for attack labs)
- Tools: Docker Engine, Wireshark, Python (venv)

## Labs
| Lab | Topic | Status |
|---|---|---|
| 01 | HTTP vs HTTPS vs DNS in Wireshark | In progress |
| 02 | Client/server, P2P and pub/sub in Python | Planned |
| 03 | MQTT security | Planned |
| 04 | VoIP: SIP and RTP | Planned |

Each lab folder has its own README with the goal, steps, findings, defense and lessons learned.

## Ethics and safety
- All tests run in my own isolated lab, on machines I own.
- I never scan, capture or attack networks or systems without permission.
- Passwords and data in these labs are fake. No real credentials or personal
  traffic are published.
- This repo is for education and defense.
